# Sound asset sources

All audio files in this directory are original project assets created specifically for Project Untitled.

## License / usage status

These files were generated in-house rather than downloaded from third-party proprietary sound libraries. Because they are original works created for this project, they are safe to include in a public GitHub repository and use in the browser game without copying protected Microsoft or commercial sound effects.

## Files and purpose

- `boot.wav` — startup / boot sequence
- `click.wav` — UI click interaction
- `close.wav` — close window
- `delete.wav` — delete / remove action
- `error.wav` — error/invalid action
- `file.wav` — file-related action
- `mail.wav` — mail notification
- `maximize.wav` — maximize window
- `minimize.wav` — minimize window
- `navigate.wav` — browser navigation
- `new.wav` — create new item
- `notification.wav` — general alert / notice
- `open.wav` — open window or folder
- `save.wav` — save action
- `search.wav` — search action
- `shutdown.wav` — shutdown sequence
- `success.wav` — success confirmation
- `warning.wav` — warning alert

## Verification

Each file was checked to confirm it is a valid WAV with a proper RIFF header and non-zero byte length.

## Notes

- No Microsoft Windows system sounds were used.
- No external copyrighted sound library content was imported.
- These effects are designed to fit a retro desktop / late-1990s PC aesthetic while remaining safe for public distribution.
